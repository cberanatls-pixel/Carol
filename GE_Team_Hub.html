Callouts & Reminders Please take note 👇
Ask Smart, Not Everything
Don't forward the whole guest message to the villa. Filter it. Ask only what is necessary.
Brand Collection ≠ Everything
It is a guide — not a checklist. Only what is available at the villa and within complimentary applies. Always verify.
FI — Clean It Up
If it is confusing to read — it is confusing to execute. Remove the unnecessary. Keep it clear.
ECI / LCO — Check the Calendar First
Back-to-back booking? Don't make the guest wait for a 48hr reply. Check the calendar. Inform them right away.
Open the ITI. Add the Task. Close It.
Every assist — open the ITI and CRM. Add the task. Done with it? Close it. No loose ends.
Re-Read Before You Send
Don't copy-paste a ChatGPT reply and call it done. Re-read it. If it sounds off — fix it before it reaches the guest.
